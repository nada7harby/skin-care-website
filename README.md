# GlowSkin - Skincare E-Commerce Platform

A skincare product e-commerce site with a full product catalog, filtering, cart, and wishlist, built with React, TypeScript, and Tailwind CSS.

## Features
- Product catalog with 16 products across 9 categories (cleansers, serums, moisturizers, and more)
- Category and attribute filtering on the product list page
- Hero carousel and animated homepage sections (best sellers, new arrivals, newsletter signup)
- Product details page with image gallery, tabbed content (description, ingredients, how to use)
- Shopping cart with responsive layout
- Wishlist/favorites with persistent storage and live count badge
- Sticky responsive header with search, favorites, and cart icons
- Page transitions and scroll animations with Framer Motion

## Tech Stack
React • TypeScript • Vite • React Router • Framer Motion • Tailwind CSS
